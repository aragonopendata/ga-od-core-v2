{% load i18n %} {% comment %} Shared deletion confirmation dialog. Any button with `data-delete-url` opens it. The button carries the already translated confirmation text in `data-delete-message`, an always-present `data-disable-hint` (disabling is the reversible alternative to deleting) and, optionally, an extra `data-delete-warning` (used for connectors, whose deletion cascades to their resources). `data-edit-url` points the secondary "Edit to disable" action at the update page for whichever row or detail page opened the modal; that link only navigates, it never mutates anything. The destructive action is always this CSRF protected POST; no GET ever deletes anything. Uses the native element, so no frontend dependency is added; browsers without it fall back to window.confirm(). {% endcomment %}
