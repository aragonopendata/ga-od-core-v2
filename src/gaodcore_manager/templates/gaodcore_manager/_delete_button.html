{% load i18n %} {% comment %} Delete trigger for the shared modal. Expects `object`, `delete_url_name`, `edit_url_name` and `is_connector`. For connectors the caller also passes `resource_count`, which the views compute (an annotation on the list, an explicit count on the detail). `edit_url_name` feeds the modal's non-destructive "Edit to disable" action, and the per-type disable hint tells administrators that disabling is the reversible alternative to deleting. Pass `icon_only=True` to render a compact icon-only control for list rows; detail pages omit it and keep the text version. {% endcomment %} {% blocktrans asvar delete_label with name=object.name %}Delete {{ name }}{% endblocktrans %} {% if is_connector %} {% blocktrans asvar disable_hint %}Disabling the connector makes all its resources unavailable without deleting their configuration.{% endblocktrans %} {% else %} {% blocktrans asvar disable_hint %}If you only want to stop publishing this resource, edit it and clear "Enabled".{% endblocktrans %} {% endif %}
